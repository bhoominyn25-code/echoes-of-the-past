# 🏛️ Echoes of the Past

### A Cultural Heritage Digital Archive of India

**Echoes of the Past** is a digital archive designed to preserve and showcase India's historical artifacts through digital technology. It brings cultural heritage closer to users through searchable artifact collections, interactive 3D visualizations, virtual heritage tours, and an AI-powered heritage guide.

## ✨ Features

- **Digital Heritage Archive** — Explore a digital collection of historical artifacts.
- **Search and Category Filtering** — Find artifacts using search and category-based filtering.
- **Interactive 3D Artifact Visualization** — View supported artifacts in an interactive 3D experience.
- **360° Virtual Heritage Tours** — Explore heritage locations through immersive virtual tours.
- **AI-Powered Heritage Guide** — Discover heritage information with the AI-powered guide.
- **Firebase Firestore Integration** — Connect the application to its cloud database.
- **Admin Content Management System** — Manage heritage content through administrative functionality.
